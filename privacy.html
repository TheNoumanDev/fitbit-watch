Privacy policy

Last updated 30 October 2026. Applies to the Fitbit Watch app (Google Cloud project "fitbit-watch").

Who uses it

Fitbit Watch is used only by its owner, with their own Google account. It is not offered to the public.

What data it accesses

With the owner's consent, it uses read-only Google Health API scopes to read activity and fitness, sleep, health metrics and measurements, profile and settings data, plus paired-device status (battery level and last sync time). It never requests write access and never changes any Google Health data.

How the data is used and stored

  • Daily summaries are saved to a file on the owner's own computer and used to draw a private dashboard and a weekly summary for the owner.
  • The sign-in token is kept in the macOS Keychain on that computer.
  • Data is not sold, shared with third parties, used for advertising, or used to train AI models.

Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access and deleting data

Access can be revoked at any time at myaccount.google.com/permissions. Deleting the local history file removes all stored data.

Contact

Questions: open an issue at github.com/TheNoumanDev/fitbit-watch.
